COMPUTERSLATE IMAGE LIBRARY

Add future website images to this folder using simple web-safe names such as school-portal-01.webp or business-pos-02.jpg.
Use relative paths like images/filename.webp in index.html. Existing carousels include fallback handling so a missing image does not break the page.
Recommended: WebP/JPG/PNG, compressed, descriptive filenames, and meaningful alt text.
